# nusantarafood
The Nusantara food project aims to develop a comprehensive ontology of food and
beverages from Malay-speaking countries (Indonesia, Malaysia, Brunei, Singapore).
The number of traditional menus from this region are enormous thus, we are currently 
focusing on developing a tool that will automatically extract food/beverage entities
and the relationships between the entities from the region mentioned.

In this way, a user in the future may benefit from a small recommendation system that will
use the ontology from our tool to advise them on the healthy diet.
